# schoolbuddy

schoolbuddy는 한국 생활 정보 접근이 어려운 다문화가정을 위해, 복잡한 제도와 행정 정보를 쉬운 언어와 단계형 설명으로 재구성해 주는 AI 상담 도우미입니다.

핵심은 단순히 LLM을 붙이는 것이 아니라, 학교·행정·복지·의료 질문을 사용자가 실제 행동으로 옮길 수 있는 형태로 구조화하는 것입니다.

## Problem
제도 정보는 검색 결과가 많아도 이해하기 어렵고, 특히 이주 배경 사용자는 용어 장벽 때문에 실제 문제 해결까지 이어지기 어렵습니다. schoolbuddy는 “정답 생성”보다 “이해 가능한 설명”을 우선순위로 두고 설계했습니다.

## Key Features
- 쉬운 한국어 기반 상담 인터페이스
- 학교 / 의료 / 행정 / 복지 / 법률 주제별 FAQ
- 사용자 상황 정보를 반영한 답변 생성
- 단계형 설명과 쉬운 용어 재서술
- AWS Bedrock 기반 스트리밍 응답

## Engineering Decisions
- FAQ 버튼과 상황 입력 필드를 통해 질문을 구조화해 모델 입력 품질을 높임
- 스트리밍 응답으로 대기 시간을 줄이고 사용자가 답변 생성 과정을 체감하도록 구성
- 프롬프트 내부에 “무슨 뜻인가요 / 왜 중요한가요 / 부모님은 무엇을 해야 하나요” 구조를 강제해 설명 품질을 일정하게 유지
- 단순 챗봇이 아니라 특정 사용자군을 위한 interaction policy를 코드 수준에서 명시

## Tech Stack
- Python
- Streamlit
- AWS Bedrock (Nova Lite)

## Limitations
- 답변 품질은 프롬프트 설계에 크게 의존함
- 현재는 외부 공공 데이터 연동보다 생성형 응답 비중이 큼
